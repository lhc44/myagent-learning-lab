# 毕业项目：企业订单与项目助手

## 学习目标
综合实现可审计的企业 Agent。完成后能独立解释数据流，并用失败实验验证边界。

## 原理与设计
项目包含模型适配、工具注册、有限循环、MCP client、上下文、检索、授权、审批、状态与评估。先完成只读查询，再加入模拟写入；真实业务上线另需安全审查。

## 数据流
```text
CLI → Runtime → Policy → Local/MCP Tools → Mock Business DB
```

## 实验与观察
以 labs/agent.py 为基础拆分 models、registry、runtime、policy、mcp、tests。使用 SQLite 保存虚构订单；构建查询订单、项目进度、检索制度、提交审批四种工具。保留调用 ID、租户 ID 和审批记录。交付架构图、运行说明、威胁模型与评估报告。

先预测输出，再运行，记录实际输出与预测差异。修改一个变量后复测，不要只截图成功结果。

## 企业场景
验收：正常查询、未知订单、越权拒绝、重复审批、模型超步数、工具异常、无工具回答均有测试。毕业项目由学习者实现，仓库实验不是生产系统。

## 验收问题
能否在不改工具的情况下切换模型？能否恢复中断的工作流？

用自己的话回答，并提交一条正常测试和一条失败测试；不能解释原因则回到原理部分。

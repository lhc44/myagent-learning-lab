# RAG 与 Tool Search

## 学习目标
理解候选检索与精细选择。完成后能独立解释数据流，并用失败实验验证边界。

## 原理与设计
RAG 检索知识；Tool Search 检索能力定义。常用步骤：切分、索引、召回、重排、组装。关键词检索对编号有效，向量检索擅长语义近似。工具筛选必须先检查权限，召回后由模型选工具；检索错误会使正确工具不可见。

## 数据流
```text
查询 → 权限过滤 → 候选召回 → 排序 → 模型
```

## 实验与观察
运行 labs/retrieval.py；修改查询词和 top_k，计算十条标注查询的 recall@k；比较关键词与同义词漏召回。进一步使用官方 embedding API 或本地模型。

先预测输出，再运行，记录实际输出与预测差异。修改一个变量后复测，不要只截图成功结果。

## 企业场景
索引必须包含租户和访问控制，引用文档需返回来源。

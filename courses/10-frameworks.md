# 成熟框架与 Java 落地

## 学习目标
用已理解的机制对照框架源码。完成后能独立解释数据流，并用失败实验验证边界。

## 原理与设计
OpenAI Agents SDK 提供工具、运行器、交接、追踪；LangGraph 用状态图组织执行与持久化；Spring AI 提供模型和工具接口、MCP 集成。框架版本变化较快，不能直接混用示例 API。

## 数据流
```text
同一业务任务 → 原生运行时 / 框架适配器 → 同样的验收测试
```

## 实验与观察
阅读三个框架官方快速开始；在独立环境复刻查询订单任务。Java 选 Spring AI BOM 和兼容 Spring Boot；用 ToolCallback 或当前官方注解注册只读方法。对比消息、工具执行点和日志，而非仅运行 demo。

先预测输出，再运行，记录实际输出与预测差异。修改一个变量后复测，不要只截图成功结果。

## 企业场景
采用接口隔离供应商 SDK；模型替换不应改变业务授权逻辑。

## 验收问题
框架替你实现了什么？安全策略应该放在哪层？

用自己的话回答，并提交一条正常测试和一条失败测试；不能解释原因则回到原理部分。

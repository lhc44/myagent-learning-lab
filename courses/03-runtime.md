# Agent Runtime 与执行循环

## 学习目标
从零实现有限步数的智能体。完成后能独立解释数据流，并用失败实验验证边界。

## 原理与设计
运行时保存消息，读取模型返回的调用列表，逐个执行并回传结果，再请求模型。无调用时结束，达到步数限制或发生不可恢复错误则失败。并行仅适用于无依赖的操作；写入重试需要幂等键。

## 数据流
```text
模型 → 是否有调用 → 执行器 → 工具结果 → 模型；无调用则结束
```

## 实验与观察
运行 labs/agent.py；把 FakeModel 改为永远调用工具，确认步数限制触发；添加两个独立调用并比较串行结果。

先预测输出，再运行，记录实际输出与预测差异。修改一个变量后复测，不要只截图成功结果。

## 企业场景
运行时独立于 HTTP Controller；为每个任务设置预算、取消和超时。

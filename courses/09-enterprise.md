# 企业安全与生产工程

## 学习目标
设计可审计、可恢复的 Agent。完成后能独立解释数据流，并用失败实验验证边界。

## 原理与设计
身份认证确认是谁，授权决定能做什么。模型不能授予权限；服务端按租户、角色和资源检查。工具输出可能包含注入指令；隔离不可信数据。执行器限制命令、网络、文件与资源。对写操作使用审批、幂等键、事务及审计。

## 数据流
```text
请求 → 身份 → 策略 → 执行 → 审计 → 响应
```

## 实验与观察
运行 workflow.py 与测试；添加另一租户订单，验证读取与写入均被拒绝。模拟超时和重试，设计幂等键唯一约束及审计字段。

先预测输出，再运行，记录实际输出与预测差异。修改一个变量后复测，不要只截图成功结果。

## 企业场景
生产环境需要独立凭据管理、最小权限、监控告警、故障回滚和数据保留策略。

## 验收问题
为什么 readOnly 标记不能作为授权依据？如何防止跨租户泄漏？

用自己的话回答，并提交一条正常测试和一条失败测试；不能解释原因则回到原理部分。

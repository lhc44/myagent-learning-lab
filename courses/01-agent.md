# Agent 基础与模型消息

## 学习目标
区分模型、应用和运行时。完成后能独立解释数据流，并用失败实验验证边界。

## 原理与设计
模型 API 接受消息与工具定义，返回文本或结构化调用。模型不负责业务执行；应用负责保存历史、发请求和验证结果。上下文不是模型持久记忆，输入长度有限。

## 数据流
```text
用户 → 消息组装 → 模型 → 输出解析
```

## 实验与观察
用 labs/agent.py 中 FakeModel 观察第一次调用与第二次最终文本；再改成直接回答。真实模型实验：用官方 SDK 打印完整响应，注意不要打印密钥。

先预测输出，再运行，记录实际输出与预测差异。修改一个变量后复测，不要只截图成功结果。

## 企业场景
模型输出不等于事实；订单状态应从授权业务接口读取。

## 验收问题
为什么同一个模型接入不同工具会有不同能力？模型是否知道执行结果？

用自己的话回答，并提交一条正常测试和一条失败测试；不能解释原因则回到原理部分。

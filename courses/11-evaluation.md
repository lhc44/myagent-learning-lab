# Agent Evaluation

## 学习目标
用数据衡量工具调用与任务完成。完成后能独立解释数据流，并用失败实验验证边界。

## 原理与设计
区分工具选对率、参数正确率、执行成功率、最终任务成功率、安全拒绝率、延迟和成本。固定任务集、模型版本、工具 schema 和测试环境。模型裁判可辅助文本评价但不能代替确定性业务断言。

## 数据流
```text
任务集 → 运行 → 记录 → 断言 → 汇总
```

## 实验与观察
执行 python -m unittest discover -s labs -v；建立 30 条测试任务，包括无工具请求、歧义、错误参数、越权、注入和正常请求。分别记录选择正确与任务成功；重复多轮评估波动。

先预测输出，再运行，记录实际输出与预测差异。修改一个变量后复测，不要只截图成功结果。

## 企业场景
发布前做回归门禁，记录版本、成本和真实错误类别。

## 验收问题
模型选对工具但最终任务失败如何分类？如何防止测试集过拟合？

用自己的话回答，并提交一条正常测试和一条失败测试；不能解释原因则回到原理部分。

# 官方资料导航
以下为优先阅读的官方入口，不复制课程正文；版本与课时随上游变化，使用前核对当前文档。

- [Hugging Face Agents Course](https://huggingface.co/learn/agents-course/en/unit0/introduction)：智能体基础、工具、框架和 RAG。
- [Hugging Face MCP Course](https://huggingface.co/learn/mcp-course/en/unit0/introduction)：协议与实际开发，界面章节可跳过。
- [Microsoft AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners)：系统设计与企业实践。
- [Microsoft MCP for Beginners](https://github.com/microsoft/mcp-for-beginners)：跨语言 MCP 实验。
- [Anthropic Building effective agents](https://www.anthropic.com/research/building-effective-agents)：区分工作流和 Agent，设计模式。
- [Anthropic Engineering](https://www.anthropic.com/engineering)：上下文、工具与工程实践。
- [MCP 官方规范](https://modelcontextprotocol.io/specification/) 与 [Python SDK](https://github.com/modelcontextprotocol/python-sdk)：协议事实以规范为准。
- [OpenAI Function Calling](https://platform.openai.com/docs/guides/function-calling)、[Agents SDK](https://openai.github.io/openai-agents-python/)：调用格式与运行时。
- [LangGraph 文档](https://docs.langchain.com/oss/python/langgraph/overview)：状态、恢复和人工介入。
- [Google ADK](https://google.github.io/adk-docs/)：工具、编排与评估。
- [Spring AI](https://docs.spring.io/spring-ai/reference/)：Java 落地。
- [BFCL](https://gorilla.cs.berkeley.edu/leaderboard.html)：函数调用评估研究。

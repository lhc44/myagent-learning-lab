开课前：这套教材怎样学习

这是面向已有编程经验、初次接触大模型智能体开发的中文工程教程。目标是理解模型与应用之间的边界，并能自己设计和开发智能体运行程序。

一、学习范围

主线假定你已经了解普通编程、HTTP 接口、JSON 和数据库，暂不学习 Gradio、网页界面或模型训练数学。我们将从模型如何选择工具开始，学习工具注册、执行循环、MCP、上下文管理、检索、权限、评估和企业架构。Python 语法只解释与本课程源码阅读相关的部分。

二、为什么实验使用 Python？

智能体并不是 Python 专属技术。模型通常通过网络 API 接收消息、工具定义并返回调用请求，因此 Java、Python、TypeScript 等语言都能实现相同的流程。选择 Python 是为了让教学代码短一些，方便直接观察消息结构、工具调用、程序执行和结果回传。多数前期实验仅使用 Python 标准库，不需要安装大型智能体框架。

Java 更适合复用现有 Spring Boot 企业服务、认证、权限、事务与部署基础设施。理解机制后，可以把 Python 实验中的模型客户端换成 Java HTTP 客户端或 Spring AI，把工具处理函数换成 Java Service，把字典换成类型明确的对象。企业工程也可以采用 Java 业务服务与 Python 智能体通过 MCP 协作的方式；不要求把现有项目重写为 Python。

课程中的 PythonJava 开发者可以怎样理解
def / class / self方法定义、类及实例对象，self 类似 this。
dict / list / NoneMap、List、null，字典可以直接转换为 JSON。
函数作为参数函数式接口或依赖注入；测试时可替换网络调用函数。
**args按参数名称展开字典，不是任意执行代码。
@mcp.tool()装饰器用于登记工具，可类比注解注册机制，但语法及执行机制不同。
async / await异步等待；不是让模型绕过程序自行执行。

每章“本章程序怎么读”直接引用实际源码并解释它做什么、为什么这样写。你不需要先学习整套 Python 语法，也不用把代码背下来。先理解业务和模型的分工，再理解执行步骤，最后尝试修改。

三、一次性准备实验环境

安装 Python 3.11 或更高版本，确认终端能执行：

python --version

Windows 如果找不到 python，可以试 py -3 --version；macOS/Linux 可使用 python3 --version。以下示例统一写 python，需要时替换成你的实际命令。

下载完整实验包

解压 ZIP，将终端切换到解压目录。所有实验文件保持在同一目录，不需要移动其中的文件。若通过 Git 克隆仓库，请先执行 cd labs。课程正文中的命令均以这个目录为起点。

python step_by_step.py local

这个命令验证本地虚构订单数据，正常时显示 A100 已付款、未发货，不请求模型。

四、从第二章开始配置真实模型

使用你已获得授权的模型接口。需要四个值：接口格式、基础地址、模型完整名称、访问密钥。第二至第四章用 Chat Completions 格式做对照实验；第五章可改用 Responses 或 Claude Messages 格式。模型必须实际支持相应功能，第三方兼容接口不保证支持所有字段。

Windows PowerShell 7.2+

$env:AGENT_API_FORMAT = "chat"
$env:AGENT_BASE_URL = "https://api.openai.com/v1"
$env:AGENT_MODEL = "替换成你有权限的模型"
$env:AGENT_API_KEY = Read-Host "输入 API Key" -MaskInput

macOS / Linux（Bash）

export AGENT_API_FORMAT=chat
export AGENT_BASE_URL=https://api.openai.com/v1
export AGENT_MODEL="替换成你有权限的模型"
read -rs AGENT_API_KEY; export AGENT_API_KEY

地址与模型都换成供应商的实际配置，不要将占位符原样运行。基础地址通常以 /v1 结尾，不要附加完整 /chat/completions 路径。旧版 PowerShell 可通过系统环境变量设置密钥。密钥只在本地使用，不填写到网页、源码、学习笔记或 GitHub。

如果接口只支持 max_tokens，根据供应商文档设置 AGENT_CHAT_LEGACY_MAX_TOKENS=1。401 检查密钥，403 检查权限，404 检查地址与模型，400 检查格式与支持的字段，429 检查配额与限流。真实请求可能收费；默认轮数和调用次数有限，但不是金额上限。

五、学习方法与当前边界

按章节阅读原理，阅读对应代码，运行实验，观察真实返回并记录问题。没有固定的逐课选择题，也不要求把所有进阶知识在第一遍学透。第 9、11 章主要安排架构设计练习。

当前教材主线可从第一章开始学习。现代 MCP 代码依据其 SDK 文档编写，实际依赖安装及接口联调仍需验证；完整 Java 企业工程、真实生产部署与真实模型评估尚未完成。离线单元测试用于验证确定性程序，不能证明模型每次都选得准。遇到失败时保留错误与实际运行记录，不要将教学中的预期结果当成实测结果。

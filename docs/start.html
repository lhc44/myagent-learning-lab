二、为什么教学代码选用 Python 标准库？（给其他语言开发者的速查表）

AI Agent 绝不是 Python 专属技术——无论你用 Java、Go、TypeScript 还是 Python，底层都是通过 HTTPS 收发 JSON 报文并调度本地业务函数。课程选用 Python 3.11+ 标准库是为了消除繁琐的样板代码与第三方依赖冲突，让你一眼看穿协议本质。如果你平时主写 Java / TS，只需对照下表即可无障碍阅读全部实验源码：

实验中的 Python 写法等价的 Java / TypeScript 概念理解
@dataclass(frozen=True)不可变数据载体，等价于 Java 16+ 的 record 或 TS 的 readonly interface。
dict[str, Any] / list[dict] / None对应 Map<String, Object>、List<Map> 与 null，可直接序列化为 JSON。
Callable[..., dict] 函数作为参数传递函数式接口 / 依赖注入（如 Function<Req, Resp>），方便在离线测试与真实请求间切换。
tool.handler(**parsed_args)将已通过白名单与类型校验的字典按参数名展开调用，绝不是任意代码执行（eval）。
with self.db:SQLite 数据库原子事务上下文：正常退出自动 COMMIT，抛异常自动 ROLLBACK（类似 @Transactional）。
async def / await异步协程 I/O 等待（与 TS async/await 一致），用于第 6 章管理 MCP 子进程管道通信。
